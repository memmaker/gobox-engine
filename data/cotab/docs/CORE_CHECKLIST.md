# CORE_CHECKLIST.md: engine → pure rules core + wgpu frontend

Goal (see ../por-go/MODERNIZED.md): keep the original texts, story, art,
maps, encounters, items, core rules and audio; replace the UI/UX, controls,
3D view, combat view, resolution and layouts.

The engine becomes a pure state changer:

    st := core.New(data, seed)        // or core.Load(save)
    q  := st.Pending()                // the Question the rules wait on
    ev := st.Step(decision)           // one synchronous call: events, new state

No goroutine, no Ebiten, no drawing in the engine. Parity matters only for
the rules.

Design: the ported routines keep their call structure. Every input point
calls `e.ask(Question) Decision`. `Step` re-runs the routines from the last
checkpoint (a deep copy of the state at a resumable point: the top of the
adventure loop, the start of a combat turn ...) with the decisions logged
since; when `ask` runs past the log it unwinds with the new question.
Deterministic: same seed + same decisions = same state. All side effects
(saves, sounds, pictures, text) leave the core as events; the frontend
performs them.
