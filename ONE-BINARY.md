# One binary: every adventure as imported data

**Goal (Felix 2026-11-11).** One `gobox` binary plays all six games (POR, COTAB, SotSB, POD, BR1, BR2) from imported data folders only. Done for the four pool games (`data/<id>/`); BR1/BR2 are REFACTOR.md B1. The track checklists and handovers that stood here are done or superseded (`core` is now `gobox/rules`); open items moved to REFACTOR.md, history is in git. Felix's decisions below still bind; read `core` as `gobox/rules`.

## Felix's decisions (2026-11-11, binding for all tracks)
- Shared Purse: default **Off** (original, per-member coins); member coins widen to 64-bit typed amounts (no clamp); on switching to Off the whole purse goes to the first member; Off pays via the WhoPays prompt at shop, temple, training; coin loot by the original Share rule; coins weigh on encumbrance.
- Sound: JSON synth data at import, synthesized at run time; music MIDI.
- Creation: core CreationRules approved, plus: Draft carries typed picks per FieldID, Name and the four picture picks (head, body, icon head, icon body); `Make(Draft) (CharID, error)` and `Draft(CharID) (Draft, error)` on CreationRules, the draft lives in gobox, KeepDraft/DropDraft go; `SetScore(Draft, Ability, value)`, 18/xx parsed in gobox; BR skills as a `FieldSkills` field kind with a point budget.
- Art collections: two families, `pool` and `buck-rogers`, each deduplicated.
- gobox/rules and gobox/rules/grid: the pure helpers move under core (money rates, purse, grid/line of sight/paths); MakeFileName goes to the engine. Leaves still import only core.
- Positions: separate typed `MapPos` and `BoardPos` in core (never mixed).
- BR1/BR2 tables: adventure data written by the importer, passed typed at Begin.
- XXVc: typed skill Hardness/Grade in core; core/xxvc rosters completed from the reconstructions (races, skills, eight saves, ship systems); core imports_test leaves gain rulesxxvc.
- Creation, more (2026-11-11): `CreationRules.Fields(d Draft)` (fields depend on earlier picks: 4e powers on class, BR career skills on career); the combat icon editor's result is a typed `core.Icon` in Draft (pool parts, six `IconColour`s, `IconSize`, or a dropped PNG); `Draft.Of CharID` (NoChar: new), so Make on a Modify updates that member, keeping items, affects, spells.
- Creation, rolled values: typed `Draft.Purse Copper` (starting money), `Draft.HitRoll int32` (hit-dice roll before adjustments), `Draft.Ident uint32` (the ruleset's identity roll, POR RandomID), so Make keeps the sheet's character.
- Delegation (Felix 2026-11-11): additive, behaviour-preserving core changes (a missing typed field or parameter that carries existing behaviour through a seam) are approved by the coordinator and logged here as "coordinator:" lines for Felix's review. Changes that alter gameplay, remove a capability or reshape an interface still go to Felix.
- coordinator (2026-11-11, for X3): xxvc.Tables gains ItemWords, Items (typed ItemTemplate) and Monsters (typed Monster), in gobox 983f6e2; core.Options gains a typed Difficulty (zero value DifficultyStandard = each game's default, BR Trooper), rulesxxvc reads it. importbr (A8) fills the new Tables fields.
- coordinator (2026-11-11, for X4): core.FightTerms gains RevivesParty and NoItemLoot (BR zone1 revivesParty, skipsCombatItems; zero = today's behaviour); rulesxxvc EndFight reads them; A8 carries them in the imported area data.
- Creation, Roll (Felix 2026-11-11): `CreationRules.Roll(d *Draft, k RollKind, r *RNG) error`; a minimum it cannot meet is a typed `*core.MinimumError` (Ability, Want/Best with strength percent, Tries for rolls spent), never matched by text; the draft stays as it was; the creation screen shows it (POR's baseline text, c70cbee: "STR 18/xx is for fighters only, max 18"; restored by C7, por-go 1455421; out-of-range typed scores clamp as in the baseline). Implementers: gobox/creation's fake, por porCreation.
- Saves (Felix 2026-11-11): rulesxxvc's Save/Load get no raw-bytes exemption: typed JSON records as in the other games; original BR saves convert once at import (A8's importer, or a typed rulesxxvc converter it calls). rulesxxvc Save/Load already write typed JSON (saved{Chars, Order, Next, Purse}); the converter from BR saves is open.
