# gobox/asset: EGA and Amiga palettes (asset/ega.go)

The original games' palettes as data: EGAPalette and the EGA* colour indexes, EGARGBA, EGARegs/EGAIdentity, the Amiga palettes (AmigaPalettes, AmigaRGBA, the Amiga* slots), and the screen size ScreenW x ScreenH. Which colour a text or element uses is chosen in ui.
